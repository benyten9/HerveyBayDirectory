The same NIBWP plugin you got from WordPress.org plus the premium runtime: file/process abilities, sandboxed PHP execution, premium integrations (Elementor, Bricks, ACF, JetEngine, EtchWP, ACSS, WPJM, …), toolkits (security, notifications, migration, content planner, SEO), and the Skill marketplace.

== Installation ==

1. Upload this zip via Plugins → Add New → Upload. If the free NIBWP plugin is already active in the same folder, this overwrites it — no duplicate to deactivate.
2. Open NIBWP → License, paste the key you received from https://nibwp.com/, and click Activate. The premium features unlock immediately.
