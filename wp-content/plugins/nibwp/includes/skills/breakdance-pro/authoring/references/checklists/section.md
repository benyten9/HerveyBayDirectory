# Generic section

- Wrapped in a Section. Vertical rhythm comes from the section, not from margins on the children.
- Heading level follows the page: `h2` under the hero's `h1`, never skipping to `h4` because it looked right.
- Container constrains the width. Full-bleed is a decision, not a default.
- Reuse an existing selector or preset if the site already styles this kind of block.
- No wrapper that exists only to hold one child.
