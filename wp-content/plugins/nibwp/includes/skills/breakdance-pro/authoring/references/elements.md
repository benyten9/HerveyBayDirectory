# Element families

This file is orientation, not a catalogue. The catalogue is
`nibwp/breakdance-pro-elements`, read live from the site — it is authoritative
and this file is not.

| Family | Typical use |
|---|---|
| Layout | Section, Container, Div, Columns — structure and spacing |
| Text | Heading, Text, Blockquote, Basic_List, Checkmark_List |
| Media | Image, Video, Icon, Gallery, Slider |
| Interactive | Button, Advanced_Tabs, Advanced_Accordion, Form builder |
| Dynamic | Posts_Loop, Dynamic_Data_Loop, Term_Loop_Builder, Post_Meta |
| Navigation | Menu, Breadcrumbs, Back_to_Top |
| WooCommerce | Product grids, cart, checkout, single-product parts |

The core element subplugin ships roughly 165 elements. Which of them exist on a
given site depends on the license, the active subplugins and any third-party
packs — so read the registry rather than trusting this table.
