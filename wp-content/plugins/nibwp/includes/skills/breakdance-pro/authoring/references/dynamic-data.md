# Dynamic data and loops

## Loop elements
`nibwp/breakdance-pro-elements action=loops` lists what this install offers.
Typically `Posts_Loop`, `Dynamic_Data_Loop`, `Term_Loop_Builder`, `PostsList`.

## When to loop
Ask one question: **will this content change or grow?**

| Content | Answer |
|---|---|
| Team members, products, testimonials, posts, events | Loop |
| Three feature blurbs fixed at launch | Static |

Repetition alone is not the test. Repetition plus change is.

## The plan
`nibwp/breakdance-pro-loop-plan` returns the steps: pick or create a post type,
add fields for what differs between the copies, replace the repeated nodes with
one loop element, bind each field with dynamic data, move the content across.

Creating the post type and the fields is a **separate decision the user makes**.
Propose it; do not do it unasked.

## Inside a loop
Bind fields dynamically. Typed text inside a loop shows the same value for every
item, which looks like a bug and is one.
