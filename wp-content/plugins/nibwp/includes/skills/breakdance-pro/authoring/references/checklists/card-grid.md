# Card grid

- Three or more cards with the same structure: offer the loop before building them by hand.
- If static is chosen, say why in the summary so the next person knows it was a decision.
- Cards are siblings in one container, not nested in each other.
- Every card image has alt text describing that card, not the same text repeated.
- Card heading level is consistent across the grid.
- Equal-height behavior comes from the layout controls, not from a fixed height.
