# Checklist — section

A generic section still has a job, and the job is the heading.

- [ ] Wrapper with `tag: section` and a meaningful `label` — `refine` targets labels.
- [ ] One heading, at the level the page outline needs.
- [ ] Padding on the section via `css` on `%local%`.
- [ ] No module left with nothing in it.
- [ ] Classes in `tagClass` as an array, matching what the site already uses.

Before committing: `nibwp/builderius-pro-build { dry_run: true }` and read the
version plan. A commit is a version somebody else will read.
