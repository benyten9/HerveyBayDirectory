# Checklist — testimonial

A quote needs an attribution or it is marketing copy.

- [ ] The quote is a `blockquote`, the attribution is not inside it as plain text.
- [ ] A name and a role, or no attribution block at all.
- [ ] An avatar has `attrAlt` with the person's name.
- [ ] Several testimonials with the same shape are a `Collection` candidate.

Before committing: `nibwp/builderius-pro-build { dry_run: true }` and read the
version plan. A commit is a version somebody else will read.
